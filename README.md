# Ninja Chess Grandmaster Edition Pro (Android)

A modern cyber-themed Chess game built for Android using Kotlin and Jetpack Compose, rewritten from the web application.

## Features

- **Full Chess Engine**: Implements strict standard chess rules including castling, en passant, pawn promotion, check, checkmate, and stalemate detection.
- **Game Modes**:
  - **Vs AI**: Play against the Ninja Pro AI powered by a minimax algorithm with alpha-beta pruning.
  - **2 Player (Pass & Play)**: Play locally on the same device.
- **Cyberpunk Visual Design**: Neon cyan and magenta accents, custom dark gradient background, coordinate labels, in-check pulse animations, and glowing highlights.
- **Dynamic Audio**:
  - Synthesized move and capture sound effects (custom PCM audio).
  - Background music playback featuring the Ryuk theme (`ryuk_theme.mp3`) with toggle mute/unmute.
- **Timers & Move Ticker**: Independent 5-minute circular timers for both players and live move history ticker.
- **Controls**: Undo move, Offer Draw, Resign, and Reset with confirmation dialogs.
- **Custom Adaptive Icon**: Cyber knight silhouette emblem with adaptive launcher icon support.
